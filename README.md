# Samanea-saman-Database
Code for the Samanea saman database

Project Description
SSDB (Samanea saman Database) is a comprehensive platform dedicated to genomic data of the Rain Tree (Samanea saman). It integrates high-quality genome sequences, annotation information, and gene expression data to support multi-omics research and comparative genomic analysis.

Users can query gene functions and sequence information and download multi-omics data through interactive tools, with applications in breeding, ecological adaptation, and medicinal value studies. SSDB is committed to advancing the exploration and utilization of genetic resources in this important tropical tree species, providing open-access data support for researchers, breeders, and conservation biologists.
